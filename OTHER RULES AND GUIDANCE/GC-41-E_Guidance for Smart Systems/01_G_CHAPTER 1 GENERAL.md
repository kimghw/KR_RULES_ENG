# Guidance for Smart Systems

> OTHER RULES AND GUIDANCE / GC-41-E / 2025 / EN / Guidance

## CHAPTER 1 GENERAL

### Section 1 General

#### 101. General

- **1.** With the advancement of information and communication technology and the digitalization of the shipping industry, there has been an increase in the installations of equipment to collect data related to the operation of ships through various means and to utilize the collected data to optimize ship operations. Such data-related equipment plays an important role as an infrastructure that enables the smart functions in ships.
- **2.** With the widespread use of digital solutions available for the maritime industry and technological developments through increased connectivity, information and data can be used to further optimize vessel operations and reduce environmental pollution. For this, stable data collection and data exchange through a certain level of standardization and data quality management are required.
- **3.** This digitization introduces new risks to cybersecurity and data security that must be managed.

#### 102. Objective

- **1.** The purpose of this Guidance is to ensure the safety and reliability of the smart systems on ships.
- **2.** This Guidance provides a set of requirements to support reliable and secure data collection, storage, and transmission.
- **3.** This Guidance provides criteria for Smart notation.

#### 103. Scope

- **1.** The requirements of this Guidance apply to smart systems, including data acquisition on board ships, ship's data consumers, data relay components and data flow to remote data consumers.
- **2.** The **Smart** notation in accordance with this Guidance can be applied to both existing and new ships.
- **3.** This Guidance does not cover the infrastructure related to remote control or autonomous operation of ships.

#### 104. Drawings and data to be submitted

- **1.** For smart systems subject to initial survey, the following drawings and data are to be submitted for reference to the Society. In addition, if deemed necessary by the Society, additional drawings and data other than those specified below may be requested.
  - **(1)** Operation manual
  - **(2)** Functional description
  - **(3)** System configuration
  - **(4)** System Specifications
  - **(5)** Test procedure

#### 105. Equivalency

For the equivalence of alternative designs and new technologies that are not satisfactory or applicable to this Guidance, it is to be in accordance with **Pt 1**, **Ch 1**, **105**. of **Rules for the Classification of Steel Ships**.
**106 Modification of requirements**
Since ship’s smart system-related technology is under development, the requirements of this Guidance may need to be supported by additional information and requirements, on a case by case basis. Designs that are not in compliance with this Guidance may be approved after evaluation by the Society, provided that it can be demonstrated that the design represents an equal or better level of safety.


### Section 2 Class Notations

#### 201. Class Notations related to smart system function

- **1.** Smart-related class notations are basically processed at the request of the shipowner.
- **2.** Depending on the installation and function of the smart system in accordance with the requirements of this Guidance, the following class notation may be assigned.
  - **(1)** Smart(INFRA)
    - **(A)** Smart(INFRA) notation can be assigned to ships equipped with infrastructure to perform smart system functions, i.e., hardware and software installed to perform data processing functions.
    - **(B)** Smart(INFRA) notation can be assigned alone, and is a prerequisite for receiving additional notation related to smart system functions such as structure health monitoring(SHM), machinery health monitoring(MHM), and energy efficiency management(EEM).
  - **(2)** Smart(SHM)
    - **(A)** Smart(SHM) notation can be assigned to ships with the system for monitoring the condition of the hull structure.
  - **(3)** Smart(MHM)
    - **(A)** Smart(MHM) notation can be assigned to ships with the system for monitoring the operating status of on-board machine equipment and systems.
  - **(4)** Smart(EEM)
    (5 Smart(NAV)
    - **(A)** Smart(EEM) notation can be assigned to ships with the system for monitoring the relevant information in order to maintain/ improve the efficiency of the on-board system or the ship itself.
    - **(A)** Smart(NAV) notation can be assigned to ships with the system for functions that support navigation.
    - **(B)** Ships with autonomous navigation functions, such as collision avoidance, are covered in the Guidance for Autonomous Ships.
- **3.** In order to assign class notations to smart system functions such as Smart(SHM), Smart(MHM), and Smart(EEM), the requirements for Smart(INFRA) class notation are to be satisfied.
- **4.** The smart-related class notation may be a single class notation or a combination of class notations. For example, Smart(MHM, EEM) refers to a ship that has the capability to monitor the operating status of on-board machine equipment and systems and a function to monitor ship’s efficiency among other smart system functions.
- **5.** When a smart system function is applied to a specific device or system, the relevant device or system may be specified as a special feature in addition to the applied smart system function. For example, Smart(MHM-D/G) refers to ships with the function to monitor the health of diesel generator, among other smart system functions.

#### 202. Other smart technologies

- **1.** In addition to the Class Notation-related technologies according to the implementation of the smart system function specified in **201.**, functions such as cargo management can be installed on the smart platform and utilized for ship operation.
